# Inventory Tracker Frontend

React and Vite dashboard for Inventory & Sales Tracker Pro.

## Run

From this directory:

```bash
npm install
npm run dev
```

The frontend runs at `http://localhost:3000` and expects the backend API at `http://localhost:3001`.

Build for production:

```bash
npm run build
npm run preview
```
